# 🔓 PDF Password Recovery & Instant Unlocker

A modern, fast Web Application to recover lost passwords on authorized PDFs and instantly download unlocked (password-free) PDF documents.

## 🚀 1-Click Free Deployment Guide

You can host this application **100% Free Forever** on **Streamlit Community Cloud**.

### Step 1: Push this project to GitHub
Open your terminal in this folder and run:
```bash
git init
git add .
git commit -m "Initial commit for PDF Password Unlocker Web App"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

### Step 2: 1-Click Deploy on Streamlit Cloud (Free)
1. Go to [share.streamlit.io](https://share.streamlit.io/) and sign in with GitHub.
2. Click **"New app"**.
3. Select your repository, Branch `main`, and Main file path `app.py`.
4. Click **"Deploy!"**.

Within 1 minute, you will get your permanent live URL (e.g. `https://your-name-pdf-unlocker.streamlit.app`) that works on both Mobile and Desktop!
